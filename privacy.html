Privacy Policy

This application accesses the TikTok Content Posting API solely to upload video content, created by the operator, as private drafts to the operator's own TikTok account.

Data collected: the operator's own TikTok OAuth access and refresh tokens, obtained via TikTok's Login Kit and stored locally on the operator's own server. No data about any other TikTok user is collected, stored, or processed.

Data use: access tokens are used only to call the Content Posting API to upload the operator's own video drafts. Tokens are never shared with, or transmitted to, any third party.

Data retention: tokens are stored locally for as long as the application is in use and are deleted if the operator revokes the application's access in their TikTok account settings.

Third parties: no data is sold, shared, or used for advertising.
